# حساب‌یار | HisabYar — Accounting for Shops, Wholesalers & ISPs

A complete Dari accounting system for shops, wholesalers and internet service providers. Runs locally on one computer, fully offline, with a simple web interface anyone can learn in a day.

## Features | امکانات
- Customers and suppliers with full balance history
- Cash and credit sales, purchases, payments and expenses
- Inventory with units and unit conversion (e.g. 1 sack = 50 kg)
- Split payments, bill discounts, purchase returns
- Loans from people — record borrowing and repayments per person
- Debtors report and WhatsApp debt reminders
- Daily USD⇄AFN rate and converter
- Profit & loss, trial balance and daily reports
- Automatic daily backup

## Editions
- **HisabYar (ISP edition)** — includes internet package (GB) sales and customer traffic
- **HisabYar General** — for shops and wholesalers, no internet section

## Tech stack
Python · Flask · SQLite · HTML/CSS

## Sample data
`sample-data.json` contains fictional demo information (sample shop, customers, products and sales) so you can see the data structure. No real business data is included.
